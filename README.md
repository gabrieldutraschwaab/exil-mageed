# Exil Mageed

Projeto de um RPG de ação em visão superior desenvolvido em Python com a biblioteca Pyxel.

## Sobre o jogo

O jogador controla um mago que foi expulso de seu reino de forma injusta por ser acusado de matar a própria esposa. A fim de descobrir a verdade sobre quem matou sua amada e conseguir vingança do reino humano, o jogador deve explorar diferentes reinos, enfrentar inimigos e procurar um pergaminho que possui magias antigas que foram proibidas e seladas.

## Características principais

1. RPG de ação com visão superior
2. Combate em tempo real
3. Exploração de diferentes reinos
4. Sistema de atributos, magias e inventário
5. Inimigos e chefes com habilidades diferentes
6. Desenvolvimento em Python e Pyxel
